<h1 align="center">Mini Hotel Management System</h1>
<p align="center">
   A modern web application built with <b>Laravel</b> to manage a mini hotel efficiently: rooms, bookings, guests, discounts, and services.
</p>

---

## Features

**Client role:**
- Browse available rooms and services
- Create, edit, and cancel bookings
- View personal booking history and applied discounts
- Track status of bookings (confirmed / pending / cancelled)

**Staff role:**
- Full CRUD for rooms, room types, guests, bookings, services, and discounts
- Confirm or cancel bookings
- Generate reports and analytics:
  - Occupancy rates
  - Revenue statistics
  - Popular room types
  - Tracking regular clients

**Additional Features:**
- Booking management with availability check and date validation
- Seasonal and regular client discounts
- Responsive design for desktop and mobile
- Role-based access control
- Interactive dashboards and charts
---

| Layer | Technology |
